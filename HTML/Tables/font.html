1. Angkor Font

ការអប់រំគឺជាគន្លឹះដ៏សំខាន់ក្នុងការបើកទ្វារទៅរកភាពជោគជ័យក្នុងជីវិត។

2. Kantumruy Pro Font

ការខិតខំប្រឹងប្រែង និងការអត់ធ្មត់ នឹងជួយឱ្យយើងសម្រេចបានក្តីស្រមៃ។

3. Battambang Font

កុំបោះបង់សង្ឃឹម ព្រោះរាល់ថ្ងៃគឺជាឱកាសថ្មីសម្រាប់ការរៀនសូត្រ។

4. Siemreap Font

ការរៀនសូត្រ និងការរីកចម្រើន គឺជាផ្នែកសំខាន់នៃជីវិត។
